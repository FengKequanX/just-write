# 微信贴图处理

适用于多张图片配短文，不把长文输入自动改成贴图。既有本地限制为标题 20、正文 1000、图片最多 9；超限报错，不压缩或截断指定内容。

## 输入与动作

```text
bun <本技能目录>/scripts/wechat-browser.ts --markdown <配文.md> --images <图片目录> [--account <别名>]
bun <本技能目录>/scripts/wechat-browser.ts --title "<标题>" --content "<正文>" --image <图片> --save-draft [--account <别名>] [--json]
```

`--image` 可以重复。目录顺序和图片选择先核对；用户指定封面或第一张时按该顺序处理，不优化替换。

默认预填编辑器，完成后报告 `manual_handoff`。`--save-draft`（兼容 `--submit`）只有已有明确保存草稿授权时使用。贴图标题与文章标题不一致需要单独确定，不能静默截短文章标题。

## 检查

核对实际账号、图片顺序、文字完整性和预填页面。只有明确保存回执才能报告草稿已保存；通用 toast、按钮未找到或等待结束均不够。结果未知先核对，不再次点击创建。

API 的 `--type newspic` 属于另一条执行路线，使用前确认当前请求适合并具备 API 输入；不能把浏览器故障当作自动改路线的授权。接口细节以相应脚本 `--help` 为准。
