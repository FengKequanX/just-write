# 微信错误恢复

出错时先判断操作发生到了哪里。参数错误与明确业务拒绝可以修正；已提交后网络或读回失败先核对，避免重复创建。

| 问题 | 处理 |
|---|---|
| 未知账号、重复别名、多个默认 | 修正或明确账号；不静默回退全局凭证 |
| 凭证缺少半对 | 补齐同一来源的本账号凭证，不拼接不同来源 |
| API 40164（IP 白名单） | 按返回错误检查当前出口 IP，让用户在公众号对应白名单修正，再使用所选 API 路线 |
| 其他 token／权限错误 | 核对对应账号凭证及权限，不打印秘密 |
| Chrome 缺失 | 指定实际路径或补运行条件，不自动改为 API |
| 浏览器未登录或账号不符 | 由用户登录正确账号，保留本地材料 |
| 标题／摘要／正文超限 | 提供符合限制的独立平台文本或必要调整，不静默截断保护内容 |
| 封面、正文图不可用 | 修正路径或提供对应素材，不保存缺失正文的草稿 |
| 保存按钮未找到、提示不明 | 标记未知结果并检查页面／草稿列表 |
| 已获草稿 ID，读回失败 | 保留 `draft_saved`，验证标为 `unverified`，只重试读取 |
| 读回内容不一致 | 保留保存事实并标 `mismatch`，说明差异，不能再次新增草稿来证明成功 |

用户已选择 API 时，不把修白名单失败解释为可自动切换浏览器。用户明确改路线后也先核对有无旧草稿，避免重复。

结果报告包含实际动作、账号、可见错误及下一步核对；保留 Markdown、封面和本地预览。退出码 3 表示结果／验证待核验，不等于可以重做上传。日志、状态与交付中不放凭证和访问令牌。
