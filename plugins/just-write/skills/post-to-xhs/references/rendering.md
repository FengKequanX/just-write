# 轮播渲染与特殊图片

只有需要选比例、排查分页或覆盖特殊图片布局时读取。常规正文由渲染器按原顺序连续排版。

## 分页与完整性

封面在 18 张上限内。正文当前页放满后自然翻页；短段不强制独立或居中，不增加装饰结束页。标题与后续内容保持关联，段落避免留下孤立一行。末页自然留白，不靠增加段距或改写内容填满。

默认正文 42px；超限只尝试一次 40px 紧凑方案，仍超过 18 张则失败并保留旧产物，需要拆篇或获准精简。禁止截断。具体尺寸与字体由当前主题提供，不为追求不同风格随意修改渲染算法。

## 图片

图片保持正文可读宽度随文排版。长图超过剩余空间时优先在空白处断开，保留少量重叠，正文接图片尾段继续。短横图尽量完整；竖图不默认缩窄成整页。截图不做 cover 裁切，不无限缩小；低分辨率放大也无法恢复原始文字。

原始 HTML `<img>` 可以显式加 `data-xhs-image-mode`：

| 值 | 行为 |
|---|---|
| `auto` | 默认，自适应随文与分段 |
| `inline` | 随文，不自动分段 |
| `page` | 强制整图独立页 |
| `split` | 允许分段，能完整放下仍保持完整 |

只有确需覆盖自动布局时才使用。说明文字过长或块无法容纳时报告错误，不裁掉信息。

封面按指定原图比例适应，不拿微信图替代。长标题允许按渲染器策略换行，不缩短文字。

## 验收

`render-report.json` 记录采用的字号、页高、占用比例和图片分段范围。渲染成功经过文字完整性、图片顺序、连续覆盖、DOM 溢出和 PNG 尺寸检查；同时在手机预览检查标题、短段、非末页异常空白、长图文字及切片接缝。

警告用于定位，不能证明或否定全部阅读质量。修复图片、结构或字号后重新渲染，让配文、报告和 PNG 一起交付。
