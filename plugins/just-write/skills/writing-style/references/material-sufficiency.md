# 材料充分性

用于起草、实质重写、目标篇幅与现有依据不相称，或材料身份混杂的任务。充分性属于主张，不属于材料条数。

## 决策流程

1. 确定文章要回答的问题、读者知识起点和核心主张。
2. 分清材料身份：事实、作者亲历、测试记录、第三方报告、推断、建议、假设示例。
3. 检查依据支持什么对象、条件、时间、单位和范围。相关材料不等于能证明中心结论。
4. 删除不影响主线的缺口；缩小能够缩小的结论；必要公共事实可以核验；依赖私有经历或判断时问一个实质问题。
5. 按内容需要决定篇幅，不用重复意义、风险、未来等部分扩写，也不强退固定短文长度。
6. 没有实质缺口时继续完成请求。用户不允许追问时，仅使用已有支持，明确实际范围。

无法支持中心结论时说明缺口；可以交付已支持的部分或替代角度，不能用“用户要求直接写”作造事实的理由。材料不足也不禁止给出可支持的标题或结构建议。

## 按主张检查

| 文章中的主张 | 相称依据 |
|---|---|
| 产品已经提供某功能 | 发布说明、可检查产品行为等；厂商宣称与实测分开 |
| 作者亲测表现 | 条件、输入、实际输出及局限；第三方报告不能代写成“我试了” |
| 某现象很普遍 | 有范围与分母的数据；一个案例只能说明该案例 |
| 机制为何发生 | 定义、前提和推理链；必要时标明假设，不要求每段新来源 |
| 读者应采用某方法 | 使用条件、步骤及合理理由；已有测试结果如实呈现，未测试不能写已验证 |
| 事件导致某结果 | 足够的因果依据；先后顺序或同时出现不能直接证明因果 |

三份扎实材料可能支撑完整长文，五份外围材料仍可能缺中心依据。文章无需强行形成事件链：概念解释可以由定义、机制、示例和边界构成，教程可以按动作依赖推进。

## 内部工作卡

需要时简记“主张 → 依据 → 范围／缺口”。它只帮助选择结构，不默认写文件或展示给用户。不要求所有非虚构段落有独立来源；依据可以复用，推理必须可追溯到已说明的前提。

同一来源可以支撑不同层面的解释。重复段落删减以没有推进、含义重复或抽象空转为理由，不能以“这一段没有新事实”一概删除。
